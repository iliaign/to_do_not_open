# Обучение в МФТИ — упоротая аркада с пинками

pygame + клиент/сервер. Играть можно с ботом или по сети (до 4 человек).

## Запуск

```
pip install -r requirements.txt
python main.py
```

`psutil` необязателен: с ним в меню видны имена адаптеров («Radmin VPN», «Wi-Fi»), без него сети определяются по диапазону IP.

Управление: **WASD / стрелки** — двигаться, **ПРОБЕЛ** — пинок, **ESC** — в меню,
**C** или клик по адресу — скопировать адрес сервера (у хоста).
Победа в раунде: первым набрать **25** пинков, потом через 6 секунд начинается новый раунд.

## Игра по сети

**Хост:** Онлайн → Создать игру → выбрать сеть (Radmin VPN, Локальная сеть, ...) → адрес уже в буфере обмена, а игра сама появится у друзей в списке.

**Друзья:** Онлайн → Подключиться → клик по найденной игре. Если список пуст (например, в Radmin часто блокируется broadcast) — вставьте адрес кнопкой «Вставить» / Ctrl+V и нажмите «Подключиться».

Если подключиться не получается:
- Windows при первом запуске спрашивает про файрвол — разрешите Python / MFTI_Kick в частных сетях.
- Все должны быть в одной сети (один роутер или одна сеть Radmin).
- Если хост выбрал конкретную сеть, друзья из другой сети не подключатся. «Все сети сразу» слушает везде.
- У всех должна быть одна версия игры. При несовпадении игра пишет «у хоста другая версия» — обновите все файлы.

Отдельный сервер без окна: `python net.py --list`, `python net.py --ip 26.12.34.56 --name Сервер`.

## Что внутри

| Файл | Что делает |
|---|---|
| `main.py` | точка входа, окно, главный цикл меню |
| `game.py` | игровой цикл, хост и клиент |
| `ui.py` | меню: ник, выбор сети, список игр, подключение |
| `render.py` | отрисовка, боковая панель, интерполяция снимков |
| `core.py` | правила и физика (без pygame и сети) |
| `net.py` | протокол v2, сервер (поток отправки на каждого клиента), сессии |
| `netutil.py` | поиск сетевых адаптеров, варианты «в какой сети играем» |
| `discovery.py` | автопоиск игр по UDP broadcast |
| `clipboard.py` | буфер обмена без зависаний окна |
| `audio.py` | звуки, кэшируются в `cache/` |
| `settings.py` | `settings.json` с ником и последним адресом |

## Сеть

TCP, JSON-строки, протокол v2 (подробности в начале `net.py`). Сервер авторитетный и шлёт снимки 30 раз в секунду. Имена и цвета отправляются отдельно, только при изменении состава. Клиент рисует чужих игроков и объект на 100 мс в прошлом с интерполяцией, а своего игрока предсказывает сам. При пинке клиент сообщает, где видел объект, и сервер принимает пинок, если это правдоподобно (компенсация задержки). Спам пинками сервер режет паузой 0.25 с.

## Сборка в exe

`build_exe.bat` (нужен Python с pip) создаёт `dist\MFTI_Kick.exe`. Друзьям достаточно отправить этот один файл.
